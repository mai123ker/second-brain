# P1 / P2 借鉴清单（P0 一条都不许做）

> **派生说明**：依据《产品落地文档全集》§15 整理，非用户原件；原件到位请以原件替换。
> 本文件是 backlog，不是本轮任务。任何"很自然"的功能先写进这里，由人决定是否进入开发。

## P1

| 项 | 实现方式 |
|---|---|
| 判断三态（维持/修正/翻转）的密度报告 | 只报"被戳中的次数"，不报"写了多少条" |
| 未探索区域提示 | 纯统计：连续 N 天只在一条线记录 |
| 旧记录回照 | 30 天 / 90 天两窗口抽样，产 `inconsistent`，纯规则 |
| 自我 × 目标 偏差检测 | 纯统计，最高优先：「目标写的是补基础，你最近 6 条都在改方案」 |
| A/B/C 路径展开 | 只摊账单（得到/付出/前提/依据），不排序 |
| 四象限待办 | 「重要/紧急」判定必须标依据，可推翻 |
| 关系句生成 | 四种 TYPE 封闭集合，最多 3 条 |
| 悬空概念 → 成目标 | 未匹配 topic 词频 ≥2 触发 |
| 待归位改名「探索区」 | 攒 5–8 条聚类，提议收拢，用户确认 |
| 聊天式记录 | 是"对话式记录"，不是聊天机器人 |
| 桌面打包 | Tauri 2 + PyInstaller sidecar，约 3 天 |

## P2

| 项 | 说明 |
|---|---|
| 二阶碰撞（方法论抽象） | 同 topic 失败 ≥3 次且跨度 ≥30 天才允许说话；必须可触发/可复用/有失败边界，缺边界判废 |
| 本地语音 | faster-whisper，可选下载 |

## 不做

- 打卡、连续天数、成长曲线、徽章（强化"记录"而非"被纠正"，会诱导用户写废话）
- 全局图谱（可视无判断）
- 让 AI 自行生成新方法论（必变鸡汤）
- 信息流推荐 / 广告（与"对抗迎合"内核直接冲突）
