## A 形态与服务

- [ ] `python run.py --port 8000` 可启动；根路径 `/` 是**旧版文档界面**（左文件树 / 中正文 / 右对话）
- [ ] 旧版顶栏有「新版」入口，打开 `/new`；旧版可正常编辑文档、保存、搜索
- [ ] `/new` 是认知库界面：左知识树（按领域分组、可折叠）/ 中常驻长文 / 右对话与行动（tab 切换）
- [ ] 两套界面在 `/new` 顶栏与旧版顶栏各有互相跳转的入口，但**数据各自独立**
      （旧版写 `records/`，`/new` 写 `vault/`，互不改写）
- [ ] `/_legacy` 跳转到 `/`，旧书签不失效
- [ ] `/docs/tree` 等旧接口未被破坏；`records/` 原文未被改动
- [ ] 模型状态如实标注：mock / off 时显示「规则版」，不得冒充真实模型

## B 投喂与原文归档

- [ ] 文本、`.txt`、`.md`、`.docx`（标准库解析）、`.pdf`（pypdf）均可投喂
- [ ] 不支持的格式明确报错，不静默跳过
- [ ] 视频链接只给 URL 时如实说明「只登记了链接，需贴字幕 / 摘要」，程序不抓取网页
- [ ] 贴了字幕 / 摘要后能提炼，且 `source.url` 保留
- [ ] 原文单独存 `vault/sources/`，frontmatter 带 `immutable: true`，写入后字节不再变化
- [ ] 超过 2 万字时截断并显式注明，不静默丢内容

## C 知识整理规则

- [ ] 去掉口语填充词、重复句、情绪化措辞，并如实报告各去掉多少
- [ ] 知识库 `.md` 里翻遍也找不到「嗯 / 那个 / 我觉得 / 烦死了」等原文
- [ ] 对话原文的 source 标题保持中性，不把原句顺着「来源」带进知识库
- [ ] 含因果 / 条件 / 分层的归为框架，单一观察归为知识点
- [ ] 归类到制度 / 法律 / 经济运行 / 教育 / 组织 / 用户增长 / 通用认知
- [ ] 主观理解如实保留，不纠正、不拔高、不替用户下结论
- [ ] 无实质内容时如实说「没有可沉淀的内容」，不硬凑条目
- [ ] 导入 `records/` 文档时先剥 YAML frontmatter：知识库里不得出现 `title / id / stream` 这类元数据条目
- [ ] 导入按一二级标题切块，长文后半段也能被提炼；纯清单 / 空文档跳过并在结果里如实计数

## D 增量更新与框架优先

- [ ] 同一段内容重复投喂走合并，不新建重复条目
- [ ] 合并后条目带多个来源标识，且**原有陈述未被改写**
- [ ] 相似但不一致的新说法并列保留并标 `conflicts` / `unabsorbed`，不覆盖旧框架
- [ ] 左栏框架排在知识点前面；可手动把「未吸收」标为「已吸收」
- [ ] 「个人使用说明」按领域成文，框架、知识点、待对照分别列出；同一句不得既算「成型框架」又说「还没吸收」
- [ ] 同一篇记录重复点「导入现有文档」不产生第二批条目（按 origin 幂等）

## E 对话与语音

- [ ] 发送后既有回复，也有沉淀卡片（新增 / 并入 / 待对照 + 去噪统计）
- [ ] 对话原文只留在 `vault/chat.json`，不进知识库
- [ ] 投喂结果以 feed 卡片留在对话流里，刷新后仍在
- [ ] 语音按钮可用：优先浏览器 Web Speech，不支持时走 `/stt` 录音转写
- [ ] 转写文本进入输入框后可编辑再发送，不自动替用户发送

## F 处境、待办与激励

- [ ] 输入处境后给出「我面临什么问题」与 3–5 条带下一步动作的待办
- [ ] 待办引用真实存在的框架 id，或如实说明库里暂无框架
- [ ] 同一栏里不得出现自相矛盾的文案（例如同时说「没有框架」和「已有 N 条框架」）
- [ ] 相似处境被召回，并显示当时的得分与问题
- [ ] 完成待办给鼓励语 + **有真实出处**的名言
- [ ] 完成后出现回补输入框；提交后新想法走提炼链路进入知识库
- [ ] 后续相似处境能提示上次写下的重复失误

## G 检索与状态

- [ ] 全局搜索覆盖知识条目 / 原文归档 / 待办
- [ ] 点开知识条目可看整理后正文、来源清单与待对照说明
- [ ] 左栏可按标题 / 领域筛选
- [ ] 统计（框架数、待吸收、来源数、待办、对话、处境）与磁盘一致

## H 数据安全与降级

- [ ] 未配模型 / 模型报错 / mock / off 时，提炼与梳理走确定性规则版，闭环完整可用
- [ ] 导入 `records/` 现有文档时**不改动 records/ 与 _chat/ 任何文件**
- [ ] `records/`、旧界面、旧接口一律不删
- [ ] 验收可用 `MIRROR_V2_VAULT` 指向临时目录，跑完真实知识库零污染
- [ ] `python scripts/backup.py` 打出的 zip **同时包含 `records/` 与 `vault/`**，V2 知识库可恢复
- [ ] 密钥只存本机 `config.json`，接口不回传，日志与界面不打印

## U 浏览器连续操作（真实 Chrome）

- [ ] 空态给出使用引导；三栏无遮挡、无文字重叠、按钮不拥挤
- [ ] 输入一段带口语的话 → 发送 → 用户气泡、AI 回复、沉淀卡片同时出现，**中栏知识随即更新**
- [ ] 左栏出现条目 → 点开 → 中栏常驻长文、右栏对话仍在；「回到说明」可回个人使用说明
- [ ] 未吸收条目顶部显示「这条还没吸收 · 不影响使用」+ 标记吸收 / 稍后再说
- [ ] 个人使用说明、全局检索、文件投喂、视频链接（只链接 / 带字幕）逐项可点
- [ ] 写处境 → 梳理 → 勾选待办 → 出现鼓励语 → 写回补 → 提交成功
- [ ] 设置弹窗可开关，模型状态与配置一致
- [ ] 全程无 JS 运行时异常
